# Църковен Гид · Church Guide

Mobile-first web app for exploring Orthodox churches: history, icons,
artists, visitor comments, with a QR and audio guide concept.
University project (UniBIT).

**Live demo:** https://church-guide.vercel.app/ (best viewed on mobile)

## Stack
React · Vite · Tailwind CSS · shadcn/ui · React Router · Vercel

## Status
Built in 3 days as a university exam project. Data is mocked; Favorites and Profile are placeholders.
